## 2. Live Real-Model Edge Case Summary (`E1`–`E5`)

All 5 conversational edge cases were executed against the live Google Cloud Vertex AI model (`gemini-3.5-flash-lite`, project `project-03a4bace-4744-4fab-bc9`, location `global`):

1. **`E1` (Explicit Pause Confirmation Wording):** Asking to pause returns `nextStep: "confirm_pause"`, customer remains `at_risk`, and reply states: *"I can help you pause your subscription. Please click Confirm Pause below to proceed. Your subscription has not been paused yet."* Clicking **Confirm Pause** transitions status to `paused`.
2. **`E2` (Billing Question at Discount Floor):** Asking *"When does my next billing cycle start?"* at `ladder_step = 2` (`$12.50`) answers the question while preserving the `pending` `$12.50` offer and `nextStep: "checkout"`.
3. **`E3` (Polite Decline / Cancel):** Saying *"No thanks, I don't want any discount, just cancel"* transitions the open offer to `declined` and sets `nextStep: "none"` on the first cancel, then escalates cleanly on repeated cancel.
4. **`E4` (Pause Request at Discount Floor):** Requesting a pause while at `ladder_step = 2` supersedes the `$12.50` discount offer, creates a `pause` offer (`0` cents), and returns `nextStep: "confirm_pause"`.
5. **`E5` (Verbal Offer Acceptance in Chat):** Saying *"Okay, $16.25 works for me"* keeps the `$16.25` offer `pending` at `ladder_step = 1` and returns `nextStep: "checkout"` so the user can complete PayPal payment.
